chapter navigation, document search, and the 25-question practice quiz.

## GitHub Pages

Upload every file in this folder to the repository root on the `main` branch.
In **Settings → Pages**, select **Deploy from a branch**, then **main** and
**/ (root)**, and save. Open the HTTPS address shown by GitHub Pages.
`index.html` is the entry page. All image and download paths are relative.

## Phone and iPad

Open the site in your browser. Use **目录 / Contents** for chapters and
**设置 / Settings** for language and font size on small screens. Search and
practice work directly in the page. You may add the URL to your home screen
using the browser's share menu; an internet connection is needed to load it.

Answers and reading preferences are stored only in that browser's local storage.
They do not sync between devices or browsers. Clearing browser data removes them.
Reloading the page resets the timer while retaining saved answers.

答题选项和阅读设置只保存在当前设备的当前浏览器，不会在手机、iPad 和电脑间同步。
清除浏览器数据会清除记录。刷新页面会重置倒计时，但保留已保存的选项。
